AI Integration

🤖

AI-Friendly Color Names

Instead of using abstract names like "blue-500", Golem uses semantic names that AI can understand:

✅ AI-Friendly

  • primary - Main brand actions
  • text-primary - Main text content
  • surface-raised - Elevated elements

❌ Abstract Names

  • blue-500 - What's it for?
  • gray-900 - When to use?
  • slate-100 - What purpose?

Usage Guidelines

✅ Do

Use semantic color tokens for consistent AI generation:

color: var(--golem-color-text-primary); background: var(--golem-color-surface-base);

❌ Don't

Use hardcoded colors that AI can't understand:

color: #111827; background: #ffffff;
