Buttons

Primary interaction elements for user actions. Built with semantic naming for AI compatibility.

Primary Button

Main Call-to-Action

Use for the most important action on a page

<button class="golem-btn golem-btn--primary"> Get Started </button>

Secondary Button

Supporting Actions

Use for secondary actions that support the primary flow

<button class="golem-btn golem-btn--secondary"> Learn More </button>

Button Combinations

Primary + Secondary Pattern

Common pattern for forms and action panels

<div class="golem-flex golem-gap-4"> <button class="golem-btn golem-btn--primary">Save Changes</button> <button class="golem-btn golem-btn--secondary">Cancel</button> </div>

<button class="golem-btn golem-btn--primary">Get Started</button>

"Create a form with primary and secondary buttons using Golem components"

🎯 AI Output

<div class="golem-flex golem-gap-4"> <button class="golem-btn golem-btn--primary">Submit</button> <button class="golem-btn golem-btn--secondary">Cancel</button> </div>

Usage Guidelines

✅ Do

  • • Use primary for main actions
  • • Use secondary for supporting actions
  • • Keep button text concise and action-oriented
  • • Use semantic class names for AI compatibility

❌ Don't

  • • Use multiple primary buttons on one page
  • • Create custom button styles outside the system
  • • Use vague button text like "Click here"
  • • Override semantic class names with custom CSS
