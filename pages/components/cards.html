AI Integration

🤖

Semantic Card Structure

Golem cards use semantic section names that AI can understand and generate consistently:

✅ AI Benefits

  • • __header - AI knows this is the title area
  • • __body - AI knows this is main content
  • • __footer - AI knows this is for actions
  • • __title - AI can identify headings
  • • __subtitle - AI knows supporting text

💬 AI Prompt

"Create a feature card with header, body, and action footer using Golem components"

Component API

CSS Classes

Available classes for card components

Class Description Usage
.golem-card Base card container Required on all cards
.golem-card--raised Enhanced shadow variant For emphasis or importance
.golem-card__header Card header section For titles and metadata
.golem-card__body Card main content area Primary content container
.golem-card__footer Card footer section For actions and buttons
.golem-card__title Card title styling Main heading in header or body
.golem-card__subtitle Card subtitle styling Supporting text or description
