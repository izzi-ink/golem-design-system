Usage Guidelines

✅ Do

  • • Use badges for status and categorization
  • • Keep badge text short (1-2 words)
  • • Use meaningful, descriptive labels
  • • Choose appropriate sizes for context
  • • Use primary variant consistently

❌ Don't

  • • Use badges for long text content
  • • Overuse badges on a single page
  • • Use vague labels like "Item" or "Thing"
  • • Mix different badge styles randomly
  • • Use badges as buttons or links
